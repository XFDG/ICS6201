## 维护命令

在仓库根目录运行：

```bash
python tools/documents/render_sale_interviews.py --dry-run
python tools/documents/build_ai_infra_delivery.py --date 2026-10-31
```

前一项检查MD到正式PDF的映射；去掉 `--dry-run` 后渲染。后一项根据“面试／技术PDF”生成阅读目录、机器清单及外部交付ZIP，旧生成物的备份统一归入历史附件。
