## 目录约定

- `doc/`：个人简历、面试材料、公开技术文档、脱敏工作记录；旧版本统一在 `doc/旧的简历/`。
- `小红书商品/`：商品宣传文案、面试资料和技术 PDF。
- `tools/documents/`：简历、公开文档及 PDF 的生成与渲染脚本。
- `output/`：历史导出件；新产物应优先归入对应的 `doc/` 目录，而非继续扩展此目录。

提交前请确认不包含内部仓库链接、节点或路径、访问凭据、模型权重、数据集和原始运行日志。
