# 训练运行手册（公开版）

## 适用范围

本手册描述一个通用的多 GPU 视觉训练项目的启动、smoke、正式训练和恢复顺序。实际主机、数据位置、模型配置、访问方式与环境变量均由部署方自行提供。

## 推荐流程

1. 在隔离环境中安装锁定版本的依赖，并记录 Python、PyTorch、CUDA 与驱动版本。
2. 将代码、配置、数据说明和预训练权重放到受访问控制的工作目录；不要把绝对路径、凭据或数据清单写入公开文档。
3. 先运行数据检查和单步/单 epoch smoke，确认标签、加载器、模型构图、loss 与 checkpoint 写入均正常。
4. 固定随机种子、配置快照和训练参数后运行正式训练；保存聚合指标而非原始样本。
5. 中断恢复时，只从已验证的 checkpoint 恢复，并核对配置、数据版本和优化器状态是否一致。

## 验收要点

- smoke 与正式训练使用同一份配置结构；
- 多卡启动前验证 rank、数据切分和日志聚合；
- 训练完成后独立复核评估集指标和最佳 checkpoint；
- 失败时保留最小复现与脱敏摘要，避免公开原始日志和环境细节。
