## 脱密口径

- 删除了用户名、人员关系、内部主机、IP、端口、镜像仓库、共享存储路径和集群拓扑。
- 内部模型、平台、分支和项目代号均改成通用称谓。
- 内部绝对吞吐、能力分数和资源总量不直接披露；必要数据改为归一化趋势、区间或示例值。
- 不复用可能带有环境信息的原始截图、日志、请求样本和性能图。
- 公开开源项目、公开 PR/Issue、标准算法与位模式在技术上确有必要时予以保留。

## 发布建议

文章已经按 Markdown 排版。发布前建议只做三件事：选择平台封面图、按个人口吻补一段开场、再走一次所在组织的内容审批。机器脱密检查只能降低误披露风险，不能代替正式保密审查。
