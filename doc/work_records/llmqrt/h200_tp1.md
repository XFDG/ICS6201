# 单卡量化推理验证（公开版）

## 验证目标

在目标 GPU 上完成单卡量化推理的最小可复现检查，为后续多卡扩展提供已知正确的基线。

## 最小流程

1. 使用公开可取得或已授权的权重，确认配置、tokenizer 与量化 schema 兼容。
2. 启动前记录软件版本、精度、输入长度和随机性控制方式。
3. 运行短请求 smoke，核对输出格式、异常处理和显存释放。
4. 与非量化或参考实现比较关键输出，按预先定义的容差判断数值一致性。
5. 扩展到多个输入长度和 batch，并在固定统计口径下测量延迟/吞吐。

## 结论边界

单卡 smoke 仅证明该条件下的运行路径可用；不能推导出其他模型、其他量化格式、张量并行或端到端服务的结论。模型目录、环境路径、命令和原始结果均未公开。
