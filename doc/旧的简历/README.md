# 历史简历与面试材料

这里仅收纳旧版本；当前版本见 [上一级目录](../README.md)。

## 文件命名

统一为 `简短主题 M月D日.扩展名`，例如 `综合简历 8月15日.docx`、`推理简历 9月16日.pdf`。这些材料均为 2026 年；同主题同日的不同文件加序号，不覆盖，也不因重复而删除。

## 日期依据

- 检查 Word 的 `docProps/core.xml` 修改时间，并检查 PDF 的修改/生成时间。
- 沿 Git 历史追踪原路径，匹配归档文件内容的 blob；排除内容不变的重命名和复制。
- 若 Git 证明文档后来改过内容，而内部时间仍停在旧模板日期，采用内容提交日期。例如推理/训练版采用 9 月 16 日，而非模板中的 9 月 1 日。
- Word 中默认的 2013 年模板时间不采用；必要时参考同版 PDF。没有可信文档时间或匹配提交时，使用原文件最后修改时间，并标明回退原因。
- 日期按北京时间显示；它是现有证据支持的版本日期，不等于可以恢复每一次真实编辑时间。MD、Word、PDF 若修改或导出不同步，日期可能不同，不强行配成同一天。

[归档清单](归档清单_20260929.json) 保留每个文件的原路径、全部日期证据、命名依据、原始 mtime 和 SHA-256，可追溯和恢复。

## 保留范围

52 个历史文件全部保留，内容及原始文件修改时间不变。原先散落的三个 Word 解包目录归入 `Word解包附件/`，使用与对应 Word 一致的简名；其 XML、图片等附件均保留并记录校验值。

历史 Markdown 是旧版本证据，继续归档；当前简历只保留综合版一份 Markdown，面试介绍仅保留 Word/PDF。
