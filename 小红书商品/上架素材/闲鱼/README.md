## 资料范围

交付采用“面试／技术PDF”两类。面试含按公司整理的旧版复盘、按专题整理的复盘与本次新增脱敏复盘；旧版和专题版可能覆盖同一轮内容。HR与海外游戏运营等属于补充阅读，不能计作额外 AI Infra 技术面试轮次。部分旧PDF沿用原有小红书水印。

新增TXT保留在本地作为整理来源，交付包只纳入复盘PDF、技术PDF和对客目录。新增原始TXT含个人信息，不纳入本次公开Git提交。内部逐源补齐记录用于核对整理范围，不放进买家交付包。

## 本地重新生成水印

在仓库根目录运行，需要 Pillow 与中文字体：

```bash
python tools/documents/watermark_offer.py \
  '商品归档/04_历史附件/原始凭证/3DFE9DBAE7C07D7811F0A022F0CAAB68.png' \
  '小红书商品/上架素材/闲鱼/商品图/02_字节录用意向书_闲鱼草原小可汗水印.png'
```

其他电脑可加 `--font` 指定本机中文字体文件。脚本不覆盖输入文件。

## 重新整理交付包

在仓库根目录运行，需要 pypdf：

```bash
python tools/documents/build_ai_infra_delivery.py --date 2026-10-31
```

默认以仓库中的 `小红书商品/面试/`、`小红书商品/技术PDF/` 为输入，同步仓库同级的“AI INFRA 面经+知识总结”目录并在其同级生成日期版ZIP，支持用 `--output` 和 `--archive` 指定位置。机器清单存放在 `商品归档/03_整理记录/交付清单.json`；无需原始TXT、原始Offer或最初未分类的压缩包。脚本校验PDF可读性和SHA-256，保留既有PDF，遇同名不同内容时停止。
