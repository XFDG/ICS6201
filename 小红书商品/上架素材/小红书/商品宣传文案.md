# 商品名称

AI Infra 求职资料包｜面试复盘＋推理、训练、RL、CUDA 算子知识总结

## 商品描述

一套面向 AI Infra、大模型推理优化、算子开发、LLM Serving 与 MoE 方向求职的 PDF 资料包。

2026-10-31 交付版共 **39 份 PDF、481 页**，按文件 SHA-256 去除完全相同副本后统计：

- **29 份技术资料、435 页**：AI Infra／推理／训练／RL／算子优化知识问答，vLLM 与 DeepInfer，GPU 架构与迁移，MoE 系统与性能，论文及开源系统解析，AI Agent 与 Harness 扩展阅读。
- **10 份公司面试合册、46 页**：按阿里、字节、百度、MiniMax、小米、曦望、OPPO、小马、理想、智元整理，每家公司一份PDF。

同一公司合册可包含不同岗位或已确认轮次，文件数量不代表面试场次。技术资料中相近知识点也可能交叉出现。

公司合册汇集对应的技术问题和复习重点，曦望采用已确认的一、二面材料。复盘区分记录中能确认的问题和整理者补充的复习任务；题图或代码缺失处不声称完整还原原题与答案。

面试资料经过整理与脱敏，交付不包含原始录音或逐字稿。公司合册保留所收录内容的文字层与原有水印。完整目录与份数以[《交付清单.json》](../../../商品归档/03_整理记录/交付清单.json)和交付包内《00_资料目录.md》为准。

适合已有编程和深度学习基础，希望集中准备 AI Infra／推理优化／CUDA Kernel／vLLM／MoE 相关实习、校招或社招面试的人。
